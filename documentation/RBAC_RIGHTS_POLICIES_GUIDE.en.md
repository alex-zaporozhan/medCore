# RBAC rights and policies — short guide

Machine-readable router ↔ permission snapshot: [rbac_router_permissions.txt](./rbac_router_permissions.txt).

Admin UI «Rights and policies» (`/admin/rights-policies`): see [docs/frontend/pages/admin-rights-policies.md](../docs/frontend/pages/admin-rights-policies.md).
