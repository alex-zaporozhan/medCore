# Лента (пациент)

> **Аудитория:** пациент.  
> **Источник UI:** `frontend/src/app/pages/FeedPage.tsx`.

## Адрес

`/app/feed`

## Назначение

Лента материалов для пациента. Заголовок: **«Лента»**; элементы ленты отображают `title` и содержимое постов согласно данным API.

## Навигация

Отдельного пункта в компактном `mainNav` может не быть — раздел доступен по URL и внутренним ссылкам из приложения.
