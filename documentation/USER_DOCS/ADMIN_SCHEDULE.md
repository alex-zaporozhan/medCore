# Расписание

> **Аудитория:** сотрудник клиники.  
> **Источник UI:** `frontend/src/admin/pages/SchedulePage.tsx`.

## Адрес

`/admin/schedule`

## Назначение

Календарное расписание клиники: выбор клиники (при нескольких), врачей, просмотр слотов, создание и правка записей через интерфейс сетки и связанные панели (в т.ч. очередь ожидания — компоненты на странице).

- Заголовок: **«Расписание»**; переключатель клиники в breadcrumbs (`ClinicSelector`).

## Подсказка в интерфейсе

При нескольких клиниках показывается текст, что в другой клинике другие врачи и услуги — нужно выбрать клинику.
