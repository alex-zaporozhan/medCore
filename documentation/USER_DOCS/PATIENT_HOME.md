# Главная (приложение пациента)

> **Аудитория:** пациент.  
> **Источник UI:** `frontend/src/app/pages/HomePage.tsx`, навигация `AppLayout.tsx`.

## Адрес

`/app` (`ROUTE_PATHS.patient.home`)

## Назначение

Главный экран PWA после входа:

- Приветствие по времени суток (**«Доброе утро»** / **«Добрый день»** / **«Добрый вечер»**), с подстановкой имени из `GET /v1/patient/me`, если оно есть.
- Выбор клиники (сохраняется в `localStorage` под ключом `app.selectedClinicId`).
- Блок ближайшего визита и связанные карточки (см. разметку `HomePage`).
- Кнопка **«Обновить»** для принудительного обновления данных.

## Навигация

В нижнем/основном меню пункт **«Главная»** ведёт на этот маршрут.
