# Вход и регистрация пациента

> **Аудитория:** пациент.  
> **Источник UI:** `frontend/src/app/pages/LoginPage.tsx`, редирект из `AppLayout.tsx`.

## Адрес

`/login` (`ROUTE_PATHS.other.login`). Без токена доступа приложение перенаправляет сюда со всех маршрутов под `/app`, кроме страницы логина.

## Режимы экрана

- Переключатель **«Вход»** / **«Регистрация»** (`SegmentedControl`).
- Заголовок: **«Вход в личный кабинет»** или **«Регистрация в клинике»**.

## Поток

1. Ввод телефона; нормализация к виду, согласованному с бэкендом (`AuthService._normalize_phone` — см. комментарий в коде).
2. Согласия: обработка ПДн; рассылка может быть обязательной в зависимости от `useAgreement()` / `allow_registration_without_mailing_consent`.
3. Отправка кода и ввод кода подтверждения (интеграция с `useSendCode` / `useVerifyCode`).
