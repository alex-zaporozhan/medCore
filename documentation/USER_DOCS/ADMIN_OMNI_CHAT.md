# Omni-чат (переписка с клиентами)

> **Аудитория:** сотрудник клиники.  
> **Источник UI:** `frontend/src/admin/pages/AdminOmniChatPage.tsx`, навигация `AdminLayout.tsx`.

## Адрес

`/admin/omni-chat`

## Назначение

Омниканальный инбокс: переписка с пациентами по подключённым внешним каналам. В коде явно отделён от внутреннего чата команды (`staff-chat`).

- Заголовок: **«Omni‑чат — только работа»**.
- В сайдбаре пункт называется **«Чат с клиентом»**; возможен счётчик ожидания (badge `omni-waiting`).
- Доступны действия вроде отправки сообщений, вложений, быстрых ответов, переключения режима AI (см. хуки `useAdminOmniChat` и разметку страницы).
