# Скрипты только для разработки и тестов (НЕ для продакшена)

Эта папка содержит скрипты для **внутреннего** использования: заполнение большой демо-базы (посещения, оплаты, скидки, отчёты, записи вперёд) для наглядной проверки функционала.

**Перед передачей клиенту или деплоем в прод:** отключите или удалите вызов этих скриптов. В продакшене их не запускать.

- `seed_dev_full_demo.py` — полное демо: данные за прошлый месяц (оплаты, визиты, аналитика, скидки) + записи на 2 недели вперёд.
- Запуск: после `seed_demo_data` и миграций.
  - С хоста: `poetry run python -m src.scripts.dev.seed_dev_full_demo`
  - В Docker: `docker compose run --rm backend python -m src.scripts.dev.seed_dev_full_demo`
  - **Если меняли скрипт:** пересоберите образ: `docker compose build backend`, затем снова запустите команду выше.
