«Ожидает» — 10 жёлтых палитр

В коде зафиксировано: вариант H · Персиковый янтарь (--calendar-scheduled-*). Ниже — история выбора. Сначала сравните полоски цвета (фон карточки, полоска статуса, бейдж). Текст бейджа везде — графитовый ink, не коричневый. Ниже — те же A–J на карточке слота.

Канон и артефакты (не менять без согласования):
  • Палитра «ожидает» / scheduled: H — значения в frontend/src/index.css (--calendar-scheduled-bg, --calendar-scheduled-bar, --calendar-scheduled-badge-* и т.д.).
  • Токены и обводка карточек: docs/artifacts/85 plus/DESIGN_TOKENS_85_PLUS.json — cardBorder, cardShadow, согласованные с --calendar-card-border / --calendar-card-shadow.
  • Семантика слотов и модалки записи: docs/artifacts/85 plus/DESIGN_SCHEDULE_MODAL_SEMANTICS_85_PLUS.md.
  • Задачи (Kanban + модалка): те же токены расписания — модуль frontend/src/shared/taskStatusSemantic.ts: фон и левая полоса по статусу задачи (open → scheduled/H, in_progress → in-progress, on_hold → system, review → attention-denim, done → completed, cancelled → negative); приоритет — отдельный бейдж.

Блоки A–J ниже — сравнение альтернатив; активный перенос в код — только H через --calendar-scheduled-*.
