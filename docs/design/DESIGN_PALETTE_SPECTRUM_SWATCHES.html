Swiss — календарь (пять семейств семантики)

Расписание / модалка «События»: полоска слева 3px + тинт фона + тёмный текст (§3.6.3 концепта). Завершено — нейтраль + ink (§1); Идёт приём — изумруд (§1b). Positive / Neutral / System — как в токенах. Negative: опорные вишня (N1) и слива (N2) — см. §4 и §4b (сохраняем). Attention: slate (§3) + альтернативы без жёлтого — коралл / деним / лёд (§3a). Календарные hex не подменяют §3.6.2a для тостов — завести calendar.attention.* / calendar.negative.*.

1 — Positive (completed / «Завершено») — канон

Не зелёный, чтобы не путать с «Идёт приём» (§1b). Завершение = «архив / закрыто»: холодный нейтраль + полоска ink. ФИО и время — #0f1419 / #5c6d7a, не изумруд.

3a — Attention: не жёлтый (коралл · деним · лёд)

Жёлтый и янтарь на большой площади легко выглядят дёшево или уходят в коричневый. Для «посмотри сюда» без тревоги лучше мягкий розово-коралл (не вишня!), пыльный сине-серый (не яркий info-blue) или холодный циан (не teal success). ФИО — #0f1419, полоска — единственный яркий акцент. Вишня/слива в §4b без изменений.

A — Пудровый коралл

Тёплое внимание без охры: полоска rose-400, фон почти белый с розовым туманом. Отличается от негатива (вишня) — там бордо и холоднее.
