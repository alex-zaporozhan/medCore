# Пять дорогих палитр: тени, обводки, кнопки, сценарии

**Назначение:** сравнить направления и выбрать одно как канон для Mantine + CSS-токенов.  
**Не смешивать** направления на одном экране без явного правила.

---

## Общие правила для всех вариантов

| Роль | Правило |
|------|--------|
| **Тени** | Два слоя, низкая непрозрачность; без «мыльного» размытия на каждой карточке. |
| **Обводки** | `1px` на полях ввода и карточках; цвет границы **темнее фона**, но светлее текста. |
| **Кнопки** | Один **Primary** на форму/модалку; **Отмена** никогда не в том же визуальном весе, что Primary. |
| **Семантика** | Success / Warning / Danger — только смысл, не конкурируют с brand по площади. |

### Базовая иерархия действий (одинакова для всех 5)

| Сценарий | Вариант кнопки | Примечание |
|----------|----------------|------------|
| **Создать / Сохранить / Отправить / Подтвердить** | Primary `filled` | Одна на блок. |
| **Далее / Продолжить** (визард) | Primary `filled` или Secondary `outline` если рядом финальный «Отправить». |
| **Отмена / Закрыть / Назад без сохранения** | Tertiary `subtle` или `default` (белая + бордер). |
| **Удалить / Отозвать доступ** | Danger `filled` или `light` + подтверждение. |
| **Второстепенно: Экспорт, Копировать ссылку** | Secondary `outline` или `light`. |
| **Разрушительное в модалке** | Справа или слева по паттерну: `Отмена` (слабее) + `Удалить` (danger). |

## Вариант 1 — «Swiss Slate / Ink»

**Характер:** холодный клинический премиум, максимум нейтрали, бренд — глубокий сине-графит.

| Токен | Значение |
|-------|----------|
| Фон приложения | `#f4f6f8` |
| Карточка / поле | `#ffffff` |
| Бордер | `#e2e6ea` |
| Текст основной | `#0f1419` |
| Текст вторичный | `#5c6d7a` |
| Primary | `#1c2e45` (ink-navy) |
| Primary hover | `#152338` |
| Focus ring | `rgba(28, 46, 69, 0.22)` |

**Тени**

- `sm`: `0 1px 2px rgba(15, 20, 25, 0.05), 0 4px 12px rgba(15, 20, 25, 0.06)`
- `md`: `0 4px 8px rgba(15, 20, 25, 0.06), 0 16px 40px rgba(15, 20, 25, 0.08)`

**Кнопки**

| Роль | Стиль |
|------|--------|
| Primary | Заливка `#1c2e45`, текст белый |
| Secondary | Белый фон, бордер `#d0d7de`, текст `#1c2e45` |
| Tertiary | Без бордера, фон `transparent`, текст `#5c6d7a`, hover фон `#eef1f4` |
| Danger | Заливка `#b42318` или outline: бордер `#fca5a5`, текст `#7f1d1d` |
| Success (вторично) | `light` заливка `#ecfdf5`, текст `#065f46` |
