# Archive — дизайн-документы (копия)

Файлы в этой папке — **снимок** тех же артефактов, что вынесены в родительскую папку **`docs/design/`**.

- **Редактировать** и считать источником правды нужно **`docs/design/*.md`**, **`docs/design/*.json`**, **`docs/design/*.html`**, **`docs/design/*.csv`** в корне `design/`.
- Эту папку можно использовать для сравнения с прошлыми правками или как локальный бэкап; при конфликте с корнем `docs/design/` актуален **корень**.
