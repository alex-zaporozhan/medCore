## SCHEDULE (Расписание / Calendar)

### Обязательные действия
- [ ] Свободный слот кликабелен → открывает форму создания записи с предзаполненным врачом + временем
- [ ] Занятый слот кликабелен → открывает карточку записи (имя пациента, услуга, статус, телефон)
- [ ] Смена статуса записи прямо из расписания: Pending → Confirmed → Completed / Cancelled
- [ ] Фильтр по врачу (мультиселект)
- [ ] Навигация по датам: вчера / сегодня / завтра + date picker
- [ ] Цветовая кодировка статусов (Confirmed = зелёный, Pending = жёлтый, Cancelled = серый/красный)

### Обязательные состояния
- [ ] Loading: Skeleton на слоты, не белый экран
- [ ] Нет записей на дату: "На этот день записей нет" + кнопка "Создать запись"
- [ ] Нет врачей в фильтре: EmptyState

### Данные (никогда UUID)
- [ ] Отображается: patient.full_name (или "Новый пациент" если анонимная запись)
- [ ] Отображается: service.name
- [ ] Отображается: doctor.full_name в заголовке колонки

### Бизнес-правила
- [ ] Нельзя создать запись в прошлом (или предупреждение)
- [ ] Нельзя создать две записи к одному врачу на одно время
- [ ] При отмене записи — запрос причины (необязательно, но важно для аналитики)

## FINANCE (Финансы / Касса / ERP)

### Кассы (вкладка)
- [ ] Список касс с балансом каждой
- [ ] Кнопка "Создать кассу" всегда видна (не только при пустом списке)
- [ ] EmptyState если касс нет: "Добавьте первую кассу" + CTA
- [ ] Приход / расход вручную прямо из карточки кассы
- [ ] Перевод между кассами
- [ ] История операций кассы (последние N транзакций с фильтром)

### Транзакции (вкладка)
- [ ] Таблица с фильтрами: период, касса, тип (приход/расход/перевод), категория
- [ ] Экспорт в CSV / Excel
- [ ] Суммарный итог за выбранный период (visible total)
- [ ] Drill-down: клик на транзакцию → детали (связанная запись, пациент, описание)

### Зарплаты (вкладка)
- [ ] Список сотрудников с начисленным за период
- [ ] Кнопка "Начислить" / "Выплатить"
- [ ] История выплат

### Бизнес-правила
- [ ] Баланс кассы не может уйти в минус без явного подтверждения (или вообще заблокировано)
- [ ] Все суммы — Decimal, не float. Копейки важны.
- [ ] Деструктивные операции (удалить транзакцию) — confirm-диалог + причина

## CRM (Пациенты / Клиенты)

### Список
- [ ] Поиск по имени, телефону, email — с debounce 300ms
- [ ] Фильтр по статусу, последнему визиту, тегам
- [ ] Быстрые действия из строки: позвонить, написать, создать запись, открыть карточку
- [ ] Пагинация или infinite scroll

### Карточка пациента
- [ ] История визитов с датами, врачами, услугами, суммами
- [ ] Баланс (предоплата / задолженность)
- [ ] Активные абонементы / подписки
- [ ] Кнопка "Создать запись" прямо из карточки
- [ ] Кнопка "Написать" (SMS / WhatsApp / Email) прямо из карточки
- [ ] Теги / заметки
- [ ] Дни рождения видны (для Loyalty)

### Бизнес-правила
- [ ] Дубли: предупреждение при создании пациента с совпадающим телефоном
- [ ] Soft delete — пациента нельзя удалить физически, только архивировать

## DASHBOARD (Главный дашборд)

### KPI-карточки (обязательные метрики для клиники)
- [ ] Записи сегодня: total + breakdown по статусам (ожид / подтв / завершено / отменено)
- [ ] Выручка за день: сумма + дельта к вчера (%, не тире)
- [ ] Новые пациенты за день + дельта
- [ ] Отмены / неявки за день + дельта
- [ ] "К вчера" — всегда число: `+12%`, `-3%`, `0%`. Тире недопустимо.

### Лента внимания
- [ ] Конфликты / неявки требующие действия
- [ ] Каждый элемент ленты кликабелен → ведёт к источнику
- [ ] EmptyState: "Всё спокойно" с объяснением откуда берутся элементы

### Записи на сегодня
- [ ] Имя пациента (full_name, НЕ UUID)
- [ ] Имя врача (full_name, НЕ UUID)
- [ ] Название услуги (НЕ UUID)
- [ ] Статус с цветом
- [ ] Клик → карточка записи или переход в расписание

### Быстрые действия
- [ ] Кнопка "Создать запись" прямо с дашборда
- [ ] Кнопка "Открыть расписание сегодня"

## ANALYTICS / REPORTS (Аналитика)

### Обязательные отчёты для клиники
- [ ] Выручка за период (день/неделя/месяц/квартал/год)
- [ ] Загрузка врачей (% занятых слотов)
- [ ] Самые популярные услуги
- [ ] Новые vs повторные пациенты
- [ ] Причины отмен

### UI-стандарт
- [ ] Фильтр: период + клиника (если multi-tenant)
- [ ] Экспорт каждого отчёта в CSV
- [ ] Drill-down: клик на число → список записей/транзакций за этот период
- [ ] Loading: Skeleton на графики, не белый экран

## SETTINGS (Настройки)

### Обязательные разделы
- [ ] Клиника: название, адрес, телефон, логотип
- [ ] Врачи: список, добавить, редактировать, деактивировать (soft delete)
- [ ] Услуги: список, цены, длительность, категории
- [ ] Рабочее время: по врачу + по клинике
- [ ] Роли и доступы: кто что может делать

### Бизнес-правила
- [ ] Нельзя удалить врача с активными записями — заблокировать с объяснением
- [ ] Нельзя удалить услугу если она используется в активных записях

## LOYALTY (Лояльность / Абонементы)

### Обязательные элементы
- [ ] Список пакетов/абонементов с ценами и составом
- [ ] Продать пакет пациенту → привязка к patient_id
- [ ] Остаток использований виден в карточке пациента
- [ ] При оказании услуги — кнопка "Списать с пакета" вместо оплаты
- [ ] История списаний
- [ ] Срок действия пакета с визуальным индикатором

## UNIVERSAL UI STANDARDS (применяется ко всем страницам)

**Дизайн-токены админки (цвет, тени, focus):** канон Enterprise 85+ — `docs/artifacts/85 plus/DESIGN_ENTERPRISE_85_PLUS_CONCEPT.md` §3.6 (Swiss Slate / Ink).

### State Matrix — обязательно для каждого компонента с данными
```
Loading  → Skeleton (не Spinner, не белый экран)
Empty    → EmptyState: иконка + текст + CTA-кнопка
Error    → Toast/Alert + кнопка "Повторить"
Success  → форма сбрасывается, Drawer закрывается, список обновляется
```

### Data Integrity
```
UUID в UI          → 🔴 БЛОКЕР
Тире вместо дельты → 🟡 ВАЖНО  
null вместо []     → 🔴 (краш при .map())
```

### Mutations
```
Кнопка submit      → disabled={isPending}
POST/PUT/DELETE    → onSuccess: invalidateQueries([...])
Деструктивное      → confirm-диалог обязателен
Дабл-клик защита   → disabled или optimistic lock
```

### Visual
```
Минимальный размер шрифта в таблицах  → 13px
Минимальный размер шрифта в контенте → 15px
Кнопка касания (мобайл)               → min 44×44px
Длинный текст                         → truncate + title={fullValue}
Иконка без подписи                    → tooltip обязателен
```

### Navigation
```
Drawer/Modal  → закрывается по Escape + клику на оверлей
Открытие Modal → фокус на первый input
Деструктивный Drawer → кнопка "Отмена" слева, "Удалить" (красная) справа
Breadcrumbs   → при вложенности 2+ уровней
```
