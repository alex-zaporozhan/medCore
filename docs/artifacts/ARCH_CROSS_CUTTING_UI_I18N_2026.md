# ARCH_CROSS_CUTTING_UI_I18N_2026 — сквозные требования UI (роль @ARCH)

> **Статус:** обязательный контекст для **всех фаз** (S-01). Не заменяет дизайн-систему Mantine — задаёт **инварианты** модалок и языка.

---

## 1. Модальные окна: центр, «карточка»

**Решение:** отказ от паттерна «сдвиг контента влево / drawer как основной способ тяжёлых форм» в пользу **центрированной модалки** в виде **карточки** (аналог старого окна регистрации): фокус по центру экрана, затемнение фона, предсказуемая ширина и скролл внутри карточки.

| Аспект | Правило |
|--------|---------|
| Размещение | По умолчанию **centered** (`Modal` centered / аналог), не side-drawer для первичных сценариев |
| Визуал | «Карточка»: скругление, тень/граница по токенам темы; не full-bleed на весь экран без причины |
| Исключения | Узкие контексты: чат-панель, список фильтров — допускается drawer, но **не** как замена модалки записи/задачи/оплаты |
| Миграция | Постепенная: новые фичи — сразу по правилу; старые экраны — по техдолгу в рамках фазы |

**Связь:** `PRODUCT_PASSPORT_UX_DESIGN_BACKEND_2026.md` — обновлять при изменении омниканала/чата.

## 2. Язык интерфейса: русский как база; без английских «витринных» слов

**Решение:** в пользовательском интерфейсе **не использовать английские слова** там, где есть нормальный русский эквивалент. Подписи кнопок, заголовки, пустые состояния, ошибки для пользователя — **на русском**.

| Допустимо | Недопустимо в UI |
|-----------|------------------|
| Технические термины в настройках: API, URL, JWT, OAuth, webhook, JSON (как подпись поля) | `Save`, `Cancel`, `Dashboard`, `Settings` как единственный текст |
| Имена внешних брендов (Telegram, WhatsApp) | Смешение RU/EN в одной фразе без необходимости |
| Коды ошибок в скобках для поддержки | Полностью англоязычные сообщения пользователю |

**Интерфейсные обозначения «искусственного интеллекта:** в текстах для пользователя предпочтительно **«ИИ»**, а не «AI».

**Нормативка:** отдельная ссылка на НПА в продукте **не обязательна**: закон новый, практика применения нестабильна; действуем по **правилу проекта** (честно минимизируем английский в UI). При необходимости юридический блок в `agreements` дополняется позже по решению @LEAD.

**Исключения:** логи для разработчиков, имена переменных в коде, комментарии в коде — не регламентируются этим документом.

## 3. Каркас i18n (обязательно заложить): RU по умолчанию, EN для зарубежного рынка

**Решение:** внедрить **слой интернационализации** (ключи строк + локали), даже пока переведён только **русский**. Это позволит без переписывания экранов добавить **английскую** версию по запросу.

| Элемент | Правило |
|---------|---------|
| Библиотека | Один выбранный стек на фронте (например `i18next` + React-обвязка) — фиксируется в первом эпике i18n |
| Строки | Пользовательский текст только через **ключи** (`t('admin.save')`), не голые литералы в JSX (постепенная миграция с чеклистом в PR) |
| Локаль по умолчанию | `ru` |
| Локаль EN | Файлы переводов `en/*.json` (или сегменты); до готовности перевода — заглушки или дублирование RU по политике @LEAD |
| Настройка | В настройках **владельца** (уровень клиники): **«Язык интерфейса по умолчанию»** — `Русский` \| `English` (первое значение дефолт). Опционально позже: переопределение на уровне пользователя |

**Бэкенд:** сообщения об ошибках для UI — код + параметры; финальный текст на фронте через i18n **или** сервер отдаёт ключ ошибки (предпочтительно единый подход в рамках эпика).

**Связь с коробкой:** «флаг Box» — это **не** язык; язык и издание (Box/Enterprise) независимы.

## 4. Связь с коробкой и Enterprise

Правила модалок и i18n **одинаковы** для Box и Enterprise. Отличается **набор экранов** (RBAC / feature flags издания).

## 5. Справочно: что такое «роут», «флаг Box», абонементы vs лояльность

**Роут** — это **адрес страницы** в браузере после домена, например `/admin/loyalty`. У каждого роута свой экран (или общий layout). Разные роуты можно открыть в разных вкладках, дать прямую ссылку, повесить отдельные права.

**Флаг Box (издание «коробка»)** — настройка деплоя/конфига: в режиме коробки **скрыты** тяжёлые Enterprise-функции (например полная лояльность). Это **не** про язык и не про URL.

**Абонементы и лояльность — принятое решение (не альтернативы):**

Одна страница **`/admin/loyalty`**, две вкладки («Абонементы» и «Лояльность»). В **коробке** вкладка «Лояльность» скрыта; в **Enterprise** обе вкладки. Глубокие ссылки при необходимости — query `?tab=` (см. IA).

Детализация: `PRODUCT_IA_RBAC_NAVIGATION_2026.md`, `ARCH_PHASE_02_CLIENTS_SCHEDULE_2026.md`.
