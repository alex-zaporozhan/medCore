# TPF_MODULE_FINANCE — Финансы и склад (ERP)

> **Префикс TPF_** — Tech Passport Frontend. Модульный техпаспорт.  
> **Связь:** `TPF_MASTER.md` (разд. 4.6), `REV_RAG_MAP_INNOVATIONS.md` (раздел 7).

---

## 1. Назначение

Жёсткий контроль: кассы с операциями Внести/Изъять/Перевод; форма транзакции с обязательными полями; техкарты в карточке услуги; при завершении визита — Checkout Hub (чек, касса, списание материалов).

---

## 2. Структура экрана

### 2.1. Кассы (таблица)

- Колонки: название кассы, текущий баланс. В строке ActionMenu: «Внести», «Изъять», «Перевод между кассами».
- Каждое действие открывает Drawer с формой транзакции: cashbox_id (или from/to для перевода), amount, type (приход/расход/перевод), category. Обязательные поля — без них не сохранять (Relational Integrity).

### 2.2. Форма транзакции (Drawer)

- Поля: касса (выбор), сумма, тип (Приход/Расход), категория. Для перевода — касса-источник и касса-назначение.
- Валидация на фронте и бэкенде.

### 2.3. Техкарты (в карточке услуги)

- В Drawer редактирования услуги — вкладка «Расходники». Динамический список: выбор Product из селекта, количество (Amount). Пример: Шприц — 1 шт, Анестезия — 2 мл. CRUD строк техкарты.

### 2.4. Checkout Hub (завершение визита)

- Открывается при переводе записи в статус «Завершено» (или по кнопке «Открыть чекаут» из Attention Feed).
- **Блок 1 — Чек:** список оказанных услуг, кнопка «+ Добавить товар», поле скидки %, итоговая сумма.
- **Блок 2 — Оплата:** выбор кассы/способа (Наличные, Терминал, СБП, Списание с абонемента). Внесение суммы оплаты.
- **Блок 3 — Склад:** Accordion «Списание материалов». Система подставляет расходники по техкарте выбранных услуг; админ может скорректировать (например 2 шприца вместо 1). Подтверждение списания.

---

## 3. Эндпойнты

| Данные | Метод/путь | Примечание |
|--------|------------|------------|
| Кассы | GET/POST/PUT cashboxes | С балансом (вычисляемым или полем). |
| Транзакции | POST transactions (cashbox_id, amount, type, category) | Валидация обязательных полей. |
| Техкарты | В составе Service или отдельно service_consumables | Product + amount. |
| Завершение визита | POST booking complete + payments + consumables write-off | Один flow или несколько вызовов. |

---

## 4. Правила UI

- EmptyState для списка касс: «Добавить первую кассу».
- Drawer для всех форм (транзакция, редактирование услуги с расходниками). Modal только для подтверждения («Списать материалы?»).
- Checkout Hub — либо полноэкранный шаг, либо крупный Drawer/модал с вкладками/секциями.
