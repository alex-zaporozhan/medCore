## 1. OmniChat: трёхколоночный “command center”

- [ ] **1.1. Правый контекст‑панель как стандарт**
  - По ARCH в правой панели OmniChat должны быть вкладки/секции:
    - Client (карточка пациента + LTV + loyalty + forms status);
    - Timeline (записи/платежи/лиды);
    - AI (режимы, статус).
  - Сейчас OmniChat не агрегирует весь этот контекст из модулей.

- [ ] **1.2. Контекстные виджеты (premium)**
  - Добавить виджеты:
    - CRM stage + суммы (`estimated_value`/`actual_value`);
    - Loyalty: активные пакеты + баланс;
    - Forms: pending/подписано;
    - Tasks: связанные задачи + “создать задачу”.
