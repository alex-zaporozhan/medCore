# TPF_MODULE_TASKS — Задачи (Task Manager & Mission Control)

> **Префикс TPF_** — Tech Passport Frontend. Модульный техпаспорт.  
> **Связь:** `TPF_MASTER.md` (разд. 4.5), `REV_RAG_MAP_INNOVATIONS.md` (разделы 6, 12).

---

## 1. Назначение

Дисциплина персонала: задачи с обязательными полями (исполнитель, срок, привязка). Два режима отображения (Таблица и Канбан). Отдельный пул «Задачи от AI» с кнопкой «Принять в работу». На экране Mission Control — лента Attention Feed и личный блок My Focus с микро-действиями и Time-Bomb при просрочке.

---

## 2. Структура экрана

### 2.1. Режимы отображения

- **Таблица:** компактная таблица с колонками (название, приоритет, исполнитель, срок, привязка). Справа в строке — ActionMenu (Редактировать, Выполнить, Удалить и т.д.).
- **Канбан:** столбцы по статусам (Open, In Progress, Done). Карточки с заголовком, бейджем приоритета, аватаркой исполнителя, датой. Просроченные — дата красным. Drag между колонками с оптимистичным обновлением.

### 2.2. Карточка задачи

- Title, Badge приоритета (красный/жёлтый/серый), аватар исполнителя, due_date (красный если просрочено).
- Задачи от AI: иконка Robot, градиентная рамка. В блоке «Задачи от AI» кнопка «Принять в работу» (назначение на себя).
- Linked Entity: кнопка-ссылка «Открыть чат с клиентом» / «Открыть запись» внутри карточки или в Drawer.

### 2.3. Форма создания/редактирования (Drawer)

- Обязательно: assignee_id (Кому), due_date (Когда). Опционально: linked_entity (Patient, Lead, Booking). Title, описание, приоритет.
- Relational Integrity: без исполнителя и даты задача не создаётся (валидация фронт + бэкенд).

### 2.4. Mission Control (Attention Feed + My Focus)

- **Attention Feed:** лента алертов (как в Dashboard); на карточке кнопка «Взять в работу» → задача назначается на текущего админа и попадает в My Focus.
- **My Focus:** личные задачи, сортировка по SLA (время на реакцию). **Time-Bomb:** если задача висит без реакции больше порога (например 2 ч), карточка с красной пульсирующей рамкой.
- **Micro-Actions:** внутри карточки задачи кнопки под тип: «Позвонить» (иконка трубки + номер), «Отправить ссылку в WhatsApp» — без перехода на другие страницы.

## 3. Эндпойнты

| Данные | Метод/путь | Примечание |
|--------|------------|------------|
| Список задач | `GET /api/v1/admin/tasks` (filters: assignee, status, source=ai) | С полями assignee, due_date, linked_entity, source. |
| CRUD задачи | POST/PUT/DELETE tasks | Валидация assignee_id, due_date. |
| Принять в работу | `PATCH /api/v1/admin/tasks/{id}` (assignee_id = current user) | Для AI-задач. |
| Attention Feed | Как в Dashboard | Задачи в ленте с действием claim. |
| My Focus | GET tasks?assignee=me&sort=sla | Личные задачи по SLA. |

---

## 4. Правила UI

- EmptyState: «Нет задач» с CTA «Создать задачу» или «Попросить AI проанализировать расписание».
- Skeleton при загрузке таблицы/канбана.
- Drawer для создания/редактирования — справа, без Modal для формы.
- Escape закрывает Drawer.
