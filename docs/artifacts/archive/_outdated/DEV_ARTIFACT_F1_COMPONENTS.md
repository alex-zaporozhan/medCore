## 1. Цель

Привести к единому стандарту TPF/REV переиспользуемые компоненты **EmptyState** и **PageSkeleton**: EmptyState — с иконкой (размер по ТП), заголовком, описанием и одной кнопкой CTA; PageSkeleton — скелет по контуру таблицы или карточек для загрузки страниц. Запретить использование полноэкранного Loader для загрузки списков/таблиц.

## 4. Пошаговые инструкции

### Шаг 4.1. Доработать EmptyState: иконка, CTA-кнопка

**Файл:** `frontend/src/shared/ui/EmptyState.tsx`

**Действие:**

1. Расширить пропсы компонента (или создать вариант по ТП):
   - `title: string` — заголовок (как сейчас).
   - `subtitle?: string` (или `description`) — краткое описание пользы раздела.
   - `icon?: ReactNode` — опциональная иконка. По ТП: размер иконки 64, stroke 1, цвет dimmed. Рекомендация: передавать иконку снаружи, например `<IconInbox size={64} stroke={1} color="var(--mantine-color-gray-4)" />`.
   - `action?: { label: string; onClick: () => void }` — единственная главная кнопка CTA (например «Создать первую задачу»). Если передан `action`, рендерить `<Button>...</Button>` под описанием.
2. Разметка: вертикальный `Stack`, выравнивание по центру, отступы (например `py="xl"`). Сверху иконка (если есть), затем заголовок, затем описание, затем кнопка. Стили текста: заголовок — `fw={500}` или `fw={600}`, описание — `c="dimmed"` или `var(--text-muted)`.
3. Сохранить обратную совместимость: если `action` и `icon` не переданы, компонент должен работать как сейчас (только title + опционально subtitle).

**Проверка:** На странице с пустым списком можно отрендерить `<EmptyState title="Нет задач" description="Создайте первую задачу для команды." action={{ label: "Создать задачу", onClick: () => {} }} />` — отображаются иконка (если передана), заголовок, описание и кнопка.

---

### Шаг 4.2. Добавить PageSkeleton (скелет страницы: таблица или карточки)

**Файл:** Создать `frontend/src/shared/ui/PageSkeleton.tsx` (или расширить `DataSkeleton` отдельным вариантом).

**Действие:**

1. Реализовать компонент `PageSkeleton` с опциональными вариантами:
   - `variant="table"` (по умолчанию): имитация таблицы — несколько строк `<Skeleton height={24} radius="xs" />` с отступом `verticalSpacing="sm"`, сверху одна строка «заголовков» (несколько Skeleton-блоков в ряд). Количество строк задать пропом, например `rows?: number` (по умолчанию 5–8).
   - `variant="cards"`: 2–4 прямоугольника высотой ~120px с `radius="md"` в сетке (Grid или flex wrap).
2. Использовать только компоненты Mantine `Skeleton`, `Stack`, при необходимости `Grid`. Не использовать `Loader` (спиннер).
3. Экспорт: именованный экспорт `PageSkeleton`. Пропсы: `variant?: 'table' | 'cards'`, `rows?: number`, при необходимости `cardsCount?: number`.

**Проверка:** На любой странице при `isLoading` можно подставить `<PageSkeleton variant="table" />` или `<PageSkeleton variant="cards" />` — отображается скелет по контуру контента без спиннера.

---

### Шаг 4.3. Запрет полноэкранного Loader в загрузке списков

**Файл(ы):** Поиск по коду: все места, где при загрузке данных рендерится `<Loader />` или полноэкранный спиннер (например `flex: 1; justify-content: center` с Loader).

**Действие:**

1. Найти в `frontend/src` вхождения `Loader` (Mantine) или компонентов с названием типа `Loading`, `Spinner` в контексте страниц со списками/таблицами.
2. Заменить их на использование `PageSkeleton` (или `DataSkeleton` для простых списков): пока `isLoading === true`, рендерить скелет вместо контента; после загрузки — данные. Не заменять Loader внутри кнопок или маленьких индикаторов отправки формы — только загрузку страницы/списка.
3. Если таких мест пока нет — зафиксировать в коде или в комментарии к компоненту правило: «При загрузке списка/таблицы использовать PageSkeleton/DataSkeleton, не полноэкранный Loader» (например в `PageSkeleton.tsx` или в TEMPLATE_DEV_ARTIFACT).

**Проверка:** На страницах с данными (пациенты, задачи, записи и т.д.) при включённой задержке/моке загрузки отображается скелет, а не крутилка на весь экран.

## 5. Критерий приёмки

- [ ] EmptyState поддерживает опциональные иконку (size 64, dimmed) и одну кнопку CTA; обратная совместимость сохранена.
- [ ] Компонент PageSkeleton создан с вариантами `table` и `cards`; используется только Mantine Skeleton.
- [ ] Полноэкранный Loader при загрузке списков/таблиц нигде не используется; везде заменён на Skeleton или отмечено правило для будущих страниц.
