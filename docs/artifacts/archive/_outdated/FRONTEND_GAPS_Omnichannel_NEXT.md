## FRONTEND_GAPS_Omnichannel_NEXT — Omnichannel & AI в админке

### 1. Текущее состояние

- Omnichannel UI реализован на страницах:
  - `AdminOmniChatPage.tsx` — рабочее место оператора;
  - `AdminOmniChannelsPage.tsx` — управление каналами;
  - `AdminOmniAiSettingsPage.tsx`, страницы AI‑отчётов.
- В `AdminLayout` есть Spotlight c действием «Спросить AI» (`useAiAgent`).

### 2. Основные GAPS

- **FO-1:** AI‑agent в Spotlight фактически stub (см. QA/OMNI‑gaps).  
  - Для оператора UI выглядит как полноценная фича, но на деле возвращает заглушку.
- **FO-2:** уровень интеграции контекста (CRM, расписание, финансы) в Omnichannel‑UI может быть усилен:
  - сейчас переход в чат из CRM есть, но не всегда обратные мостики (к лидам, визитам, задачам).
- **FO-3:** нет визуальных индикаторов, что часть AI‑функций находится в режиме beta/ограниченной функциональности.

### 3. Инварианты для Omnichannel‑UI

1. Любая AI‑функция должна:
   - либо быть реально реализована;
   - либо явно помечена как «в разработке»/beta, чтобы не ломать ожидания.
2. Omnichannel‑экран должен выступать «операционным центром»:
   - быстрые переходы к лидам, задачам, записям и ERP‑данным.
