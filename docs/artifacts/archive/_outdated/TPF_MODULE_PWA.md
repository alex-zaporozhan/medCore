# TPF_MODULE_PWA — Пациентское PWA (Client App)

> **Префикс TPF_** — Tech Passport Frontend. Модульный техпаспорт.  
> **Связь:** `TPF_MASTER.md` (разд. 4.12), `REV_RAG_MAP_INNOVATIONS.md` (раздел 15), TECH_PASSPORT_FRONTEND_UI_LOGIC (разделы 6, PWA).

---

## 1. Назначение

PWA — лицо клиники для пациента. Должно ощущаться как нативное приложение: нижняя навигация, билет визита, сторис, запись в 3 тапа, кошелёк лояльности.

---

## 2. App Shell (каркас PWA)

- **Bottom Navigation Bar:** Фиксированная панель внизу с 4–5 иконками: Главная, Запись, Чат, Профиль. Активная — акцентный цвет. Без верхнего гамбургер-меню.
- **Safe Areas:** `padding-bottom: env(safe-area-inset-bottom)` для выреза экрана (iPhone и др.).
- **Pull-to-Refresh:** На страницах с записями и чатом — потянуть вниз для обновления.
- Мета-теги: `apple-mobile-web-app-capable`, `theme-color` для слияния с системным баром.

---

## 3. Главный экран (Home)

- **Приветствие:** «Доброе утро, [Имя]!» (или время суток).
- **Next Visit Ticket:** Если есть будущая запись — карточка-билет (Pass) с закруглениями, градиентом: дата, время, врач, услуга, кнопки «Отменить/Перенести», «Добавить в календарь», QR при необходимости. Если записей нет — EmptyState с кнопкой «Записаться».
- **Stories Bar:** Горизонтальный скролл с круглыми аватарками (как Instagram Stories). Клик — полноэкранная сторис (акции, новости). Данные: PromoPost / Story.

---

## 4. Мастер записи (Booking Wizard)

- **Visual First:** Выбор врача/мастера — крупные фото и рейтинг/отзывы.
- **Карусель дат:** Горизонтальный скролл дней (Пн 12, Вт 13…), под ним — слоты (Chips). Выбор даты сразу обновляет слоты.
- **Upsell (опционально):** Перед подтверждением — «Обычно с этой услугой берут X (+500₽). Добавить?»
- Минимум шагов; подтверждение и при необходимости предоплата по текущему flow.

---

## 5. Профиль и лояльность (Wallet)

- **Digital Wallet:** Виртуальная карта клиники, баланс кэшбэка крупно, прогресс до следующего уровня (например «Осталось 2 визита до VIP»).
- **Реферальная кнопка:** «Подарить другу 1000₽ (и получить 1000₽ себе)» — Web Share API для отправки ссылки через мессенджеры.

---

## 6. Чат (Patient)

- История сообщений, отправка текста. Соответствует текущему patient chat API. Pull-to-Refresh.

---

## 7. Эндпойнты (ориентиры)

- Текущий пациент, записи: `GET /api/v1/patient/bookings`, создание/отмена.
- Слоты: `GET /api/v1/doctors/{id}/schedule`.
- Stories/Promo: public_marketing.
- Лояльность/баланс: по модулю Loyalty (если реализован).

---

## 8. Правила UI

- Никакого верхнего глобального меню; только Bottom Nav.
- Next Visit Ticket — самый заметный блок на главной.
- EmptyState везде, где нет данных (нет записей, нет сторис и т.д.).
- Поддержка светлой/тёмной темы по системе (prefers-color-scheme).
