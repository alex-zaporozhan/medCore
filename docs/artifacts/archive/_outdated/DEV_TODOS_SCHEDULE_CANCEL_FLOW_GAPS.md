## 3. Системные задачи/сигналы по отменам (Premium retention)

- [ ] **3.1. Авто‑задача при отменах**
  - При отмене визита можно создавать:
    - `Task` “Заполнить окно” (source=system) или сигнал в AttentionFeed.
  - Это повышает операционную дисциплину и конверсию “освободившихся слотов”.

- [ ] **3.2. Интеграция с waitlist**
  - Убедиться, что:
    - при отмене слота корректно запускается уведомление waitlist;
    - есть лимиты/антиспам политика (не спамить одному и тому же пациенту).
