# Скрипты демо-данных для разработки (не для продакшена)

Скрипты в `src/scripts/dev/` предназначены **только для внутреннего** использования: заполнение большой демо-базы для наглядной проверки функционала (аналитика, отчёты, оплаты, визиты, скидки, записи вперёд).

**Перед передачей клиенту или деплоем в прод:** не запускайте эти скрипты; при необходимости исключите папку `src/scripts/dev/` из поставки или явно не вызывайте их в инструкциях для клиента.

## Что делает seed_dev_full_demo

- **Кассы:** при отсутствии создаются 2 кассы (наличные, карты) для клиники.
- **Скидки:** при отсутствии — «Первый визит -10%», «Чистка зубов -15%», период «Март -5%».
- **Прошлое (~30 дней):** записи с разными статусами (completed, cancelled, no_show, confirmed); для completed — оплаты (YooKassa) и движения по кассе (financial_transactions), чтобы отчёты и ERP выглядели заполненными.
- **Будущее (~2 недели):** записи вперёд (pending/confirmed) для проверки календаря и списков.

**Требования:** перед запуском выполнить `seed_demo_data` (клиника, врачи Demo Dr.*, пациенты +7000000*, услуги).

## Запуск

- **Из контейнера бэкенда (рекомендуется — та же БД, что и приложение):**
  ```bash
  docker compose run --rm backend python -m src.scripts.dev.seed_dev_full_demo
  ```
- С хоста (если `DATABASE_URL` указывает на ту же БД, что и бэкенд):
  ```bash
  poetry run python -m src.scripts.dev.seed_dev_full_demo
  ```

Скрипт идемпотентен по кассам и скидкам (не дублирует их), но **добавляет новые записи** при каждом запуске. Для чистого теста используйте пустую БД после миграций и seed_demo_data, затем один раз seed_dev_full_demo.
