# REV_INDEX — Навигация по документам революции UI/UX

> **Как быстро найти:** Все новые документы имеют префикс **REV_** или **TPF_**. В Cursor/IDE: поиск по `REV_` или `TPF_` в папке `docs/` покажет полный список.

---

## Префиксы

- **REV_** — революция: карты новшеств, критерии внедрения, архитектурные ценности, индекс и план.
- **TPF_** — Tech Passport Frontend: мастер-техпаспорт и модульные техпаспорта по функционалу.

## Порядок использования

1. **Начать реализацию (что за чем делать):** `REV_IMPLEMENTATION_RUNBOOK.md` — порядок фаз; `DEV_STACK_INDEX.md` — полный список артефактов; выполнять пошаговые инструкции из `docs/dev_artifacts/DEV_ARTIFACT_<ID>.md`.
2. **Понять, что внедрять:** `REV_RAG_MAP_INNOVATIONS.md` (поиск по странице или эндпойнту).
3. **Проверить приоритет и критерии:** `REV_CRITERIA_IMPLEMENTATION.md`.
4. **Правила UI по разделу:** `TPF_MASTER.md` + нужный `TPF_MODULE_*.md`.
5. **Архитектурные решения и паттерны:** `REV_ARCH_UI_VALUES.md`.
6. **План работ по фазам (критерии, эндпойнты, зависимости):** `REV_IMPLEMENTATION_PLAN.md`.
