# TPF_MODULE_SHELL — Каркас приложения (App Shell)

> **Префикс TPF_** — Tech Passport Frontend. Модульный техпаспорт.  
> **Связь:** `TPF_MASTER.md` (Часть II), `REV_RAG_MAP_INNOVATIONS.md` (раздел 2).

---

## 1. Назначение

Админ-панель должна восприниматься как профессиональный desktop-софт (Linear, Notion), а не как сайт 2010-х. Каркас задаёт навигацию, рабочую зону и глобальные механизмы поиска.

---

## 2. Компоненты и структура

### 2.1. AppShell (Mantine)

- **Header:** Отсутствует. Верхний глобальный `<AppShell.Header>` не используется.
- **Navbar (Sidebar):** 
  - Фон: тёмный (`bg="dark.8"` или `var(--bg-dark)`). Текст и иконки: белые/полупрозрачные (`c="gray.3"`).
  - Ширина: развёрнуто 260px, свёрнуто 80px. Кнопка Collapse внизу сайдбара.
- **Main:** Фон светлый (`bg="gray.0"`). Контент страниц оборачивается в `Paper` с `border: 1px solid gray.2`, `radius="xl"`.

### 2.2. Группы навигации

Группировка с заголовками (uppercase, мелкий шрифт):

- **OPERATIONS:** Дашборд, Расписание, Чат.
- **BUSINESS:** CRM, Финансы, Лояльность (если включена).
- **SYSTEM:** Настройки, Команда (администраторы), интеграции.

Активный пункт: яркий акцент (`bg="indigo.6"`, `c="white"` или по теме).

### 2.3. Context Bar (внутри Main)

На каждой странице вверху контента:

- Слева: заголовок страницы (и при необходимости хлебные крошки).
- Справа: главные кнопки действий (например «Новая запись», «Создать задачу»).

Глобальной шапки нет — контекст задаётся страницей.

### 2.4. Spotlight (Cmd+K / Ctrl+K)

- Вверху сайдбара: кнопка/плейсхолдер «Поиск... (⌘K)».
- При нажатии Cmd+K открывается `@mantine/spotlight`: поиск по разделам, поиск пациентов и записей (если реализован соответствующий API).
- Опционально: вкладка или режим «Спросить AI» — ввод текстового запроса и вызов AI-агента (Function Calling).

---

## 3. Эндпойнты и данные

| Элемент | API | Примечание |
|---------|-----|------------|
| Список разделов | — | Статическая конфигурация роутов. |
| Spotlight: поиск | `GET /api/v1/admin/search?q=...` или фильтрация существующих списков | При введении поиска — пациенты, записи, переход к разделу. |
| AI Command | `POST /api/v1/ai/agent` или аналог (function calling) | Текстовый запрос из Spotlight. |

---

## 4. Правила для разработчиков

- Не добавлять глобальный Header. Все заголовки и действия — в Context Bar страницы.
- Sidebar всегда с возможностью Collapse. Состояние (развёрнут/свёрнут) сохранять в localStorage или контексте.
- Spotlight должен открываться по Cmd+K глобально (useHotkeys в корневом layout).
- Escape закрывает Spotlight и любую открытую Drawer (если обрабатывается глобально).
