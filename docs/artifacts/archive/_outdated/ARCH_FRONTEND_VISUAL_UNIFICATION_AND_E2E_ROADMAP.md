# Визуальная унификация фронта + дорожная карта E2E (PAW) @QA_ARCH

> **Аудитория:** @QA_ARCH, @LEAD, @DEV · **Связь:** `ARCH_FRONTEND_TECH_PASSPORT_DENTAL_BOOKING.md` §2, `routePaths.ts`, `ARCH_QA_BROWSER_E2E_ENTERPRISE.md`, ADR-006.

---

## 1) Диагноз (почему «разъезжается» стиль)

| Симптом | Причина | Направление решения |
|--------|---------|---------------------|
| Разный «голубой» vs тёмное меню | Кастомная палитра `brand` (серо-голубая) не совпадала с акцентом **indigo** активного пункта в `AdminLayout` | Единый акцент **Mantine `indigo`** + токены в `:root` (`index.css`) |
| Шрифт «плохо рендерится» | В `theme.ts` был Inter, но **не подгружались файлы** шрифта | Self-host: `@fontsource/inter` (latin + cyrillic + cyrillic-ext) в `main.tsx` |
| Карточки «плоские» | Слабые `--shadow-*` | Токены `--shadow-card`, `--shadow-soft-md` с двойным слоем (rim + lift) |
| Разные страницы — разные решения | Лендинг / пациент / админ эволюционировали отдельно | Один **design contract** ниже + поэтапный PAW |

---

## 2) Глобальные решения (уже заложенные в код)

- **Тема:** `frontend/src/theme.ts` — `primaryColor: "indigo"`, Inter для текста и заголовков.
- **Токены:** `frontend/src/index.css` — фон, текст, `--primary*`, тени.
- **Карточки:** `AppCard` использует `--shadow-card`.
- **Альтернативы шрифта (бесплатно для коммерции, OFL)** — смена в одном месте (`main.tsx` + `theme.ts`):
  - **IBM Plex Sans** — «корпоративный» вид, хорошая кириллица (`@fontsource/ibm-plex-sans`).
  - **Source Sans 3** — нейтральный Adobe OFL.
  - **DM Sans** — современный UI, геометрический.

## 3) PAW — постраничный чеклист (инвентарь по зонам)

Цель каждой строки: **визуал (типографика, плотность, тени)** + **состояния §11** + **будущий E2E ID**.

|----------|------|------------|------------|
| Лендинг | `App.tsx` → `LandingPage` | Hero, CTA, блок модулей | E2E-SMOKE-01 ✓ |

### 3.2 Админка `/admin/*`

| Маршрут (канон) | Сегмент / страница | Примечание |

### 3.3 Пациент `/app/*` и публичное

**Приоритет:** зона **пациента** — высокая (PWA, контраст, единый акцент; не только админка).

| Маршрут | Страница / файл | Заметки |
|---------|-----------------|--------|
| `/login` | `LoginPage` | Вход по коду, согласованность с индиго |
| `/app` | `HomePage` | «Ближайший визит»: имена врача/услуги из API, не сырые UUID |
| `/app/booking` | `BookingWizardPage` | Select: читаемые опции (`index.css`); `useDoctors` только при выбранной клинике |
| `/app/chat` | `ChatPage` | CTA, пузыри, без «старого» голубого без `color="indigo"` где нужно |
| `/app/profile` | `ProfilePage` | — |
| `/app/history` | `HistoryPage` | — |
| `/app/feed` | `FeedPage` | — |
| `/app/*` shell | `AppLayout` | **Светлая схема PAW** (`forceColorScheme="light"`, без `pwa-respect-system`): не «чёрный экран» при тёмной ОС. Клиника: цвет только шапка/нижняя панель; дефолт `indigo.6`; нижняя навигация только `< sm` |

**Правило:** новые правки UI — через токены (`:root`, Mantine theme), не локальные «магические» цвета без причины.

## 4) Уровни E2E (связь с ADR-006)

| Уровень | Содержание | Статус |
|---------|------------|--------|
| **A** | Публичный smoke лендинга | ✓ `e2e/smoke-public.spec.ts` |
| **B-0** | Shell маршрутов без auth (`/`, `/admin/login`, `/login`) | ✓ `e2e/smoke-routes.spec.ts` |
| **B-1** | API поднят, seed клиники/пользователя, логин админа → виден `AdminLayout` | эпик: `globalSetup` + секреты CI |
| **B-2** | Пациент: verify-code flow с mock/тестовым Redis | эпик |
| **C** | Критичные journey (запись, оплата) | по `DOMAIN_STANDARDS` |

Инфраструктура для B-1+: `docs/RUN_SERVICES.md`, `docker-compose.yml`, переменные из `.env`.

## 5) Критерии готовности «единого стиля» (DoD визуала)

- [ ] Акцентные кнопки и ссылки используют **indigo** (или осознанное исключение в PR).
- [ ] Новые карточки — `AppCard` или те же токены тени/границ.
- [ ] Нет регресса читаемости на кириллице (проверка визуально / скриншот-тест опционально).
- [ ] Для изменённых экранов — пункт из `DOMAIN_STANDARDS` по типу страницы.
