# TPF_MODULE_DASHBOARD — Дашборд (Action Center)

> **Префикс TPF_** — Tech Passport Frontend. Модульный техпаспорт.  
> **Связь:** `TPF_MASTER.md` (разд. 4.1), `REV_RAG_MAP_INNOVATIONS.md` (раздел 3).

---

## 1. Назначение

Дашборд — не просто статистика, а центр управления сменой: метрики, лента событий, требующих реакции, и таймлайн ближайших записей.

---

## 2. Структура экрана

### 2.1. Верхний ряд (Top Bar)

Четыре метрики в виджетах:

1. **Записей сегодня** — число + динамика (например +5% к вчера), при необходимости Sparkline.
2. **Выручка** — сумма за день/период + динамика.
3. **Новые лиды** — количество + динамика.
4. **NPS / Отмены** — компактный показатель и тренд.

Под каждой метрикой — микро-график (Sparkline) и процент роста к прошлой неделе. Зелёная стрелка при росте, красная при падении.

### 2.2. Левая колонка (~60%) — Attention Feed

Лента карточек событий, требующих внимания:

- Типы (с цветовой кодировкой):
  - Критично (красный): пациент отменил запись на сегодня → кнопка «Предложить окно листу ожидания».
  - Финансы (оранжевый): визит завершён, но касса не закрыта → «Открыть чекаут».
  - AI-Ассистент (индиго): ИИ ведёт диалог с конфликтным тоном → «Вмешаться в диалог».
  - Склад (жёлтый): остаток ниже критического → «Создать задачу на закупку».
- На каждой карточке — кнопка «Взять в работу» (перенос в My Focus).

### 2.3. Правая колонка (~40%) — Таймлайн расписания

Вертикальный список записей на сегодня:

- Карточки: время, пациент, врач, услуга. Индикатор статуса (ожидает / в кресле / завершён).
- Зелёный кружок — в кресле, серый — ожидает. Клик по карточке открывает Drawer записи.

### 2.4. Опционально: виджет «Спасённая выручка (AI)»

Если реализован AI Revenue Hunter: блок «Выручка, спасённая ИИ за ночь» (например +5 000 ₽).

## 3. Эндпойнты

| Данные | Метод/путь | Примечание |
|--------|------------|------------|
| Метрики (записи, выручка, лиды, отмены) | Агрегаты по клинике за период | Существующие отчёты или новые сводные эндпойнты. |
| Attention Feed | `GET /api/v1/admin/attention-feed` или аналог | Список событий с типом и payload для кнопок. |
| Таймлайн на сегодня | `GET /api/v1/admin/clinics/{id}/schedule?date=today` | Тот же schedule с фильтром по дню. |
| Claim алерта | `PATCH /api/v1/admin/attention-feed/{id}/claim` или через задачу | Перенос в My Focus (назначение на текущего админа). |

---

## 4. Правила UI

- При пустом Attention Feed — EmptyState с текстом «Пока всё спокойно» (не пустая колонка).
- При пустом таймлайн — EmptyState «Нет записей на сегодня».
- Загрузка: Skeleton для виджетов метрик и двух колонок, без полноэкранного Loader.
- Кнопки на карточках Feed ведут к конкретному действию (открыть Drawer записи, чекаут, чат, задачу).
