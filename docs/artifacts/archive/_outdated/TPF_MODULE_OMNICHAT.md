# TPF_MODULE_OMNICHAT — Омниканальный чат (Smart Hub)

> **Префикс TPF_** — Tech Passport Frontend. Модульный техпаспорт.  
> **Связь:** `TPF_MASTER.md` (разд. 4.3), `REV_RAG_MAP_INNOVATIONS.md` (раздел 4).

---

## 1. Назначение

Чат — операционная среда. Администратор не должен уходить со страницы, чтобы записать клиента, выставить счёт или отправить форму. Всё доступно из трёхколоночного интерфейса.

---

## 2. Структура экрана (три колонки)

### 2.1. Левая колонка — Smart Inbox

- Список чатов с бейджами:
  - `[Ждёт ответа]` (красный) — последнее сообщение от клиента.
  - `[AI ведёт диалог]` (синий) — включён автопилот.
  - `[Черновик]` (жёлтый) — админ начал писать, но не отправил.
- Фильтры-таблетки сверху: Все, Неотвеченные, От VIP, С ошибкой оплаты (и т.п.).
- В превью под именем — не только текст, но и системные ивенты: «🔄 AI записал на 14:00», «💳 Оплата 5000₽ получена».

### 2.2. Центральная колонка — Чат (Canvas)

- Лента сообщений (bubbles): клиент / админ / AI с подписью.
- **Над полем ввода:** AI Magic Suggestions — до 3 кнопок с вариантами ответа по контексту последнего сообщения. Клик вставляет текст в поле (или отправляет).
- **Rich Bubbles:** Ссылка на оплату отображается как карточка: «Счёт #123 на 5000₽ [ОПЛАЧЕНО / ОЖИДАЕТ]» с обновлением статуса в реальном времени.
- **Action Bar под полем ввода:**
  - Запись (Calendar) → открывает Drawer создания записи с предзаполненным телефоном пациента.
  - Счёт (CreditCard) → модалка/мини-Drawer: сумма → «Отправить ссылку в чат».
  - Анкета (FileText) → выбор формы и отправка ссылки в чат.
  - AI вкл/выкл (Robot) — тумблер автопилота для этого чата.
- Hotkeys: Cmd+J — фокус поиск чатов, Cmd+Enter — отправить сообщение.

### 2.3. Правая колонка — Контекст клиента (Command Center)

- Блок 1: Идентификация — аватар, ФИО, уровень лояльности (LTV, кол-во визитов), при необходимости бейдж «Часто отменяет».
- Блок 2: Таймлайн — следующий визит (дата, время, врач) с кнопками «Изменить время», «Отменить»; если визита нет — последний визит + «Записать снова».
- Блок 3: Этап воронки (LeadStage) — выпадающий список для быстрого перевода (Лид → Думает → Записан и т.д.).
- Блок 4: Внутренние заметки — текстовое поле с жёлтым фоном (стикер). Только для админа, клиент не видит.
- Кнопка **«Создать запись»** — открывает Drawer с предзаполненным телефоном/пациентом.

## 3. Эндпойнты

| Данные | Метод/путь | Примечание |
|--------|------------|------------|
| Список чатов | Существующие omnichannel/chats | С флагами: last_from_client, ai_enabled, draft. |
| Сообщения | Существующие messages | + тип system для ивентов (запись создана, оплата). |
| AI Suggestions | `POST /api/v1/ai/suggest-replies` или в контексте чата | Контекст последних сообщений. |
| Статус платежа | Webhook или poll для Rich Bubbles | Обновление карточки «Ожидает» → «Оплачено». |
| Пациент, визиты, лид | Patient, Bookings (next), LeadCard | Правая колонка. |
| Создать запись | `POST /api/v1/admin/bookings` | С patient_id/phone из контекста. |
| Ссылка на оплату | Платёжный API (YooKassa) | Генерация и отправка в чат. |
| Отправить форму | Paperless API | Ссылка на форму в чат. |
| AI вкл/выкл | Настройки чата/контакта | OmnichannelAiSettings или per-chat flag. |

---

## 4. Правила UI

- Drawer записи и модалки счёта/формы не уводят с страницы чата — открываются поверх или сбоку.
- EmptyState: если чатов нет — «Нет диалогов» с подсказкой по подключению каналов.
- Skeleton при загрузке списка чатов и истории сообщений.
- Escape закрывает открытый Drawer, не закрывая сам чат.
