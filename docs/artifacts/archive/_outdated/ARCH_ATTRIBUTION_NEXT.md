## ARCH_ATTRIBUTION_NEXT — домен Marketing Attribution

### 1. Краткое описание домена

Attribution‑домен отвечает за честную сквозную аналитику:

- от клика/UTM до лида, записи, визита и денег;
- оценка эффективности кампаний и каналов;
- отчёты для владельца/маркетолога.

### 2. Актуальная модель сущностей (по коду / BUSINESS_LOGIC_CURRENT/V2)

По `BUSINESS_LOGIC_V2` и коду (`public_marketing.py`, `admin_marketing_attribution.py` и отчётные сервисы):

- `TrafficSource` / `Campaign` (в коде могут быть представлены как сущности или расширения имеющихся таблиц);
- расширения в `LeadCard` (utm‑метки, source);
- связь с `FinancialTransaction` (доход по визитам/лидам).

Роутеры:

- `public_marketing.py` — фиксация атрибуции визитов/заходов;
- `admin_marketing_attribution.py` — отчёты по атрибуции.

### 3. Целевая модель vNext

1. **Полная UTM‑цепочка:**
   - фиксировать UTM при первом заходе (на лендинге/PWA);
   - связать:
     - `utm` → `LeadCard` → `Booking` → `FinancialTransaction`;
   - хранить и показывать на уровне CRM/отчётов.

2. **Отчёты ROI по кампаниям:**
   - расходы по кампаниям (вносятся вручную или через интеграцию);
   - доход и LTV по кампаниям;
   - вывод в отчётах владельца/менеджера.

3. **Интеграция с AI и Tasks:**
   - выявление неэффективных/суперэффективных кампаний (AI‑анализ логов);
   - генерация задач по оптимизации маркетинга.

### 4. Связи с другими доменами

- **CRM:** лейблы/source/utm в лидах.
- **Booking:** переходы от лида к записи/визиту.
- **ERP:** фактические деньги по визитам.
- **Reports:** визуализация и дашборды; отчёт **ROI по источникам** (`roi-by-source`) — предагрегат и фоновый пересчёт по плану **`ARCH_DEV_ERP_VITRINES_026.md`**, **`ARCH_DEV_ERP_VITRINES_026_TASKS.md`** (модуль **026-6**).
