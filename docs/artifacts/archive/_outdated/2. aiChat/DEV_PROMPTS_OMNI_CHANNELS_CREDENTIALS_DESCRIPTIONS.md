## 9. Чек-лист для @DEV

1. Открыть `frontend/src/admin/pages/AdminOmniChannelsPage.tsx`.
2. Для каждого типа канала (TELEGRAM_BOT, WHATSAPP_BUSINESS, VIBER_BOT, VK_BOT, MAX_CHAT, SMS_GATEWAY, EMAIL_INBOX, OTHER):
   - Найти соответствующий блок с `TextInput` / `Textarea`.
   - Для каждого поля добавить или заменить атрибут `description` на текст из таблицы выше.
   - Где указан placeholder в таблице — добавить или обновить `placeholder` у `TextInput`.
3. Не менять ключи в `CredentialsFormState` и в объекте `payload` при сохранении — только подписи и подсказки.
4. Проверить в браузере: модалка «Настройка ключей» для каждого типа канала показывает актуальные подсказки под полями.

**Готовность:** все поля формы настроек каналов имеют однозначные подсказки в стиле «ID чата админа», согласованные с официальной документацией мессенджеров и с `ARCH_OMNI_CHANNELS_CREDENTIALS_FIELDS.md`.
