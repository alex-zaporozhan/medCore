# SALES_OBJECTION_LIBRARY

> **Назначение:** единая библиотека возражений для пресейла (BOX + ENTERPRISE).  
> **Правило:** каждый ответ опирается на подтверждённые артефакты, без overpromise.

---

## 1) Как пользоваться

1. Выбери возражение клиента.
2. Используй “safe response” (без самодеятельности).
3. Покажи “evidence to show”.
4. Если evidence нет — не обещай, зафиксируй как follow-up.

## 4) Универсальные hard rules для sales

1. Нет evidence -> нет обещания.
2. Нет ясного scope -> нет цены “под ключ”.
3. Любой спорный пункт фиксируется в follow-up с owner и сроком.
4. BOX и ENTERPRISE не смешиваются в одном оффере без явного разделения.
5. Любая фраза, противоречащая контрактам, считается sales-risk.
