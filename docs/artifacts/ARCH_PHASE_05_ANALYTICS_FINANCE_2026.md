# ARCH_PHASE_05_ANALYTICS_FINANCE_2026 — фаза 5 (роль @ARCH)

> **Ссылка:** `MASTER_PRODUCT_ROADMAP_2026.md` § фаза 5.

## 1. Цель

Дашборды **без LTV/ROI** для коробки; починка Finance/Reports; агрегаты по выручке, визитам, специалистам, статусам клиентов; скрытие Enterprise-страниц в профиле Box.

## 2. Границы

Чтение из согласованных источников: транзакции, визиты, ERP-агрегаты (если включены воркеры). Не строить вторую «теневую» бухгалтерию без явного ADR.

## 3. Данные

Материализованные представления или кэш по `clinic_id`; тяжёлые отчёты — асинхронно или лимит окна.

## 4. Мультитенантность

Сводки строго в разрезе клиники; сетевые отчёты — только с ролью и явным списком `clinic_id`.

## 5. Безопасность

Финансовые endpoint — только владелец/разрешённые роли; админ без права — 403.

## 6. UI

Виджеты на русском; без англ. ярлыков в пользовательских подписях.

## 7. Риски

Расхождение «экран vs ERP» — документировать источник истины.

## 8. Зависимости

Наличие корректных оплат/визитов (фазы 2–4).
