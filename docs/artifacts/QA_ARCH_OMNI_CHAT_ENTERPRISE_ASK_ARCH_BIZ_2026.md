# Задача @ARCH + @BIZ: Enterprise-шаблоны омничата и функциональная оптимизация

> **Инициатор:** @QA_ARCH (качество рабочего места оператора).  
> **Связь с архитектурой:** `ARCH_PHASE_03_OMNI_CHAT_2026.md`, `MASTER_PRODUCT_ROADMAP_2026.md` (фаза 3).

## Контекст

Экран «Единый чат» — ключевое рабочее место администратора. Без явного соответствия отраслевым паттернам enterprise-инбоксов интерфейс воспринимается как устаревший: мало полезной плотности, слабая предсказуемость действий, длинный путь до типовых операций.

## Запрос к @ARCH

1. **Свести эталоны** (не как маркетинг, а как паттерны UX): например, Zendesk Agent Workspace, Intercom Inbox, Salesforce Service Cloud / Messaging, Freshdesk / Freshchat, HubSpot Conversations, Genesys Cloud agent desktop, Microsoft Teams (политики enterprise для чатов), где уместно — сравнение с **PWA/веб** для агентов, не для клиента.
2. **Выделить обязательные блоки** для «коробки» Dental Booking:  
   трёхколоночная сетка, composer, контекст пациента/лида, статусы канала/AI, быстрые действия (запись, задача, форма), очередь/незакрытые, доставка/прочитано по политике канала.
3. **Оформить результат** как короткий **шаблон спецификации экрана** (структура секций + приоритеты Must/Should/Could) и приложить к `ARCH_INDEX_PHASES_2026.md` или отдельному `ARCH_OMNI_AGENT_WORKSTATION_2026.md` после согласования.

## Запрос к @BIZ

1. **Процессы:** SLA-first response, эскалация, VIP/платёжные риски, назначение на оператора/очередь, макросы и быстрые ответы, теги темы диалога.
2. **Метрики для приоритизации бэклога:** что измеряем в проде (время до первого ответа, % закрытых без переноса, ошибки по каналам).
3. **Выход:** 1–2 страницы **Product brief** для омничата как «рабочей станции», с явным списком **user stories** для @DEV (приоритизированный бэклог).

## Ожидаемый результат для @DEV

После входных от @ARCH и @BIZ — единый артефакт **«Omni Agent Workstation — Enterprise backlog»** (таблица: возможность, эталон, приоритет, зависимости от API/ролей), чтобы разработка не расходилась с «как делают в отрасли» и с бизнес-процессами клиники.
