# ARCH_PHASE_06_OWNER_RBAC_2026 — фаза 6 (роль @ARCH)

> **Ссылка:** `MASTER_PRODUCT_ROADMAP_2026.md` § фаза 6.

## 1. Цель

Категории персонала, гранулярные права, политика «владелец открывает вкладки»; подготовка профиля **BOX**: какие маршруты и пункты меню скрыты.

## 2. Границы

RBAC — сервер истины; фронт только отражает. Новые permissions — миграция + `seed_rbac_baseline` согласованно.

## 3. Данные

Таблицы ролей, связей роль–permission, переопределения на пользователя; аудит изменений политики (минимум лог).

## 4. Мультитенантность

Политики могут различаться по клинике (будущее); в v1 — глобальные роли с привязкой пользователя к клинике — уточнить в реализации без нарушения изоляции данных.

## 5. Безопасность

Нет эскалации прав через UI; проверка на сервере для каждого API.

## 6. UI

Конструктор прав — центрированные формы; все термины RU.

## 7. Box cut

Чеклист: скрыть `/admin/retention`, Enterprise-аналитику; на `/admin/loyalty` скрыть **вкладку** «Лояльность» (коробка), вкладку «Абонементы» оставить.

## 8. Зависимости

Фазы 1–5 для осмысленного набора permissions.
