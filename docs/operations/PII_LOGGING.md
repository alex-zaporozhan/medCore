# PII в логах (SME §2.4)

## Политика

- В **структурированных JSON-логах** (`LOG_FORMAT=json`) маскируются **последовательности, похожие на телефоны** (RU: +7 / 8 / 10–11 цифр), см. `src/core/pii_mask.py`.
- Поля `message`, `exception`, а также строковые значения в `extra` проходят через маскирование при **`LOG_MASK_PII=true`** (по умолчанию).
- **ФИО** и **email** в общем случае не ищутся эвристикой; не логируйте их в `extra` без необходимости. Критичные потоки — только через роли и минимальный объём данных.

## Переменные

| Переменная | Значение |
|------------|----------|
| `LOG_MASK_PII` | `true` / `false` (default: true в коде) |
