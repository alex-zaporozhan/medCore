# Offboarding арендатора и экспорт данных организации (LEAD + OPS + Product)

> **Связь:** [SAAS_STRENGTHENING_MASTER_PLAN.md](../architecture/SAAS_STRENGTHENING_MASTER_PLAN.md) §15b (DoD **1e**), §24; [DR_RUNBOOK.md](./DR_RUNBOOK.md).

## 1. Назначение

Единый черновик процедур для **приостановки / отключения** организации (Владелец уходит) и **выгрузки** данных в machine-readable виде до полной реализации UI в кабинете Основателя.

## 2. Триггеры

- Запрос Владельца на закрытие договора.
- Неоплата / расторжение по правилам платформы (Product).
- Юридическое требование (через SEC/юриста).

## 3. Offboarding (последовательность)

1. **Зафиксировать** тикет: `organization_id`, причина, ответственный OPS/LEAD.
2. **Приостановить** доступ админки (feature flag / отключение логинов организации — по реализации RBAC).
3. **Отозвать** публичные ключи: API key embed и webhook-секреты — через админку **«Встраивание (embed)»** (`/admin/embed`, отзыв ключей и повторная ротация webhook secret) либо напрямую API `POST /api/v1/admin/organization/embed/api-keys/{id}/revoke` (§24).
4. **Уведомить** каналы omni по политике (закрытие очередей или автоответ).
5. **Финальный срок** хранения данных — по договору и privacy; до истечения — режим «только чтение» для Владельца при необходимости.
6. **Удаление / архивация** БД-строк: только по явному шагу после бэкапа и проверки экспорта (см. §4).

## 4. Экспорт данных (machine-readable)

**Минимальный состав** (уточняется Product до первого реального запроса):

- Метаданные организации и клиник.
- Пациенты и контакты — в объёме, разрешённом договором и 152-ФЗ.
- Записи, платежи, CRM-лиды — по доменным таблицам тенанта.

**Формат:** JSONL или CSV по согласованию; **шифрование** архива (пароль отдельным каналом).

**Сроки:** целевой SLA внутренний — N рабочих дней (заполнить в тикете); не публиковать как договорный SLA без юриста.

**Логирование:** кто инициировал, когда выдан архив, хэш файла (без хранения пароля в логах).

## 5. Ответственность

| Роль | Действие |
|------|----------|
| **Product** | Состав данных экспорта, сроки, тексты для Владельца |
| **DEV** | Скрипты/API выгрузки per `organization_id`, изоляция от других тенантов |
| **OPS** | Выполнение, бэкап перед удалением, хранение выгрузки |
| **SEC** | Доступ к выгрузке, маскирование PII в логах |
| **LEAD** | Приёмка процедуры перед «enterprise» обещаниями в маркетинге |

## 6. Проверка после реализации в коде

- Негативный тест: экспорт **не** включает `organization_id` чужого тенанта.
- Runbook обновить ссылкой на фактический endpoint или скрипт.
