# TPF_MODULE_FORMS — Формы (Paperless)

> **Префикс TPF_** — Tech Passport Frontend. Модульный техпаспорт.  
> **Связь:** `TPF_MASTER.md` (разд. 4.7), `REV_RAG_MAP_INNOVATIONS.md` (раздел 8).

---

## 1. Назначение

Конструктор шаблонов форм и отправка форм в контексте пациента или записи: генерация уникальной ссылки и доставка в WhatsApp/SMS.

---

## 2. Структура экрана

### 2.1. Список шаблонов

- Таблица (или карточки) шаблонов: название, тип, дата изменения. Data Density, ActionMenu в строке (Редактировать, Дублировать, Удалить).
- Кнопка «Создать шаблон» открывает Drawer с конструктором (поля по JSON-схеме или визуальный редактор).

### 2.2. Редактор шаблона (Drawer)

- Поля по выбранной схеме (например анкета здоровья, согласие). Сохранение как DigitalFormTemplate.

### 2.3. Отправка формы из контекста

- В ActionMenu карточки пациента или записи — пункт «Отправить форму». Выбор шаблона → генерация уникального URL → отправка в WhatsApp/SMS (или копирование ссылки). Backend создаёт запись об отправке и возвращает URL.

---

## 3. Эндпойнты

| Данные | Метод/путь | Примечание |
|--------|------------|------------|
| Шаблоны | GET/POST/PUT/DELETE form_templates | CRUD. |
| Отправить форму | POST form/send-link (patient_id или booking_id, template_id) | Возврат URL; опционально вызов отправки в канал. |

---

## 4. Правила UI

- EmptyState: «Нет шаблонов» с CTA «Создать шаблон».
- Drawer для создания/редактирования шаблона. Modal для подтверждения удаления.
- В чате (OmniChat) кнопка «Анкета» из Action Bar использует тот же механизм отправки формы.
