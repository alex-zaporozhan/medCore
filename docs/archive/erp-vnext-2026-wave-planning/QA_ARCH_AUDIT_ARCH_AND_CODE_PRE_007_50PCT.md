## 3. Средние (надёжность, сопровождение, согласованность процесса)

### 3.1 Шина событий: каскадный отказ подписчиков — **закрыто**

**Было:** при исключении в одном обработчике цикл `publish` прерывался — остальные подписчики на то же событие не вызывались.

**Сделано:** в `EventBus.publish` каждый хендлер в своём `try/except`; ошибки логируются (`logger.exception`), счётчик `domain_event_handler_failures_total{event_name,handler}` в `src/core/metrics.py`. Тесты: `tests/services/test_event_bus.py`.

**Опционально на будущее (не регрессия):** dead-letter / outbox для критичных цепочек — отдельный пакет, если понадобится гарантия доставки между процессами.

### 3.2 Трекер исполнения и доказательства закрытия пакетов — **закрыто (процесс)**

**Было:** риск путаницы между `[x]` в трекере и фактическим содержанием TASKS.

**Сделано:** в `DEV_EXECUTION_TRACKER_NEXT.md` §0 добавлен явный пункт **«Источник правды закрытия пакета»** — парный `./ARCH_DEV_*_TASKS.md` (раздел «Выполнено» / итог Stabilize / финальный чеклист).
