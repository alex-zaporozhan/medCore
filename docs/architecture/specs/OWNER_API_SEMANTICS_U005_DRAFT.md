# Черновик целевой семантики `/owner/*` (U-005)

> **Статус:** черновик Phase 0; **не** расширять маршруты под префиксом `/owner/*` до закрытия U-005 решением LEAD + Product (мастер-план §17, [UNRESOLVED_AND_CONFUSION_LOG.md](../UNRESOLVED_AND_CONFUSION_LOG.md)).

## Факт текущей реализации (код)

- Роутеры `owner_omni_*` используют **`get_current_admin`** и область **`current_admin.clinic_id`** (одна клиника на запрос).
- JWT и роль **не** отделяют «владельца сети» от администратора клиники; префикс **`/owner/`** — номенклатурный, не доменный.

**Якоря:** `src/api/v1/routers/owner_omni_channels.py` и соседние `owner_omni_*.py`.

## Продуктовые цели (на выбор LEAD / Product)

| Вариант | Смысл | Последствия для API |
|---------|--------|---------------------|
| **A — переименование** | Сохранить поведение «админ текущей клиники» | Перенос префикса на нейтральный (`/admin/omni/...` или `/clinic/omni/...`), OpenAPI + миграция клиентов |
| **B — сетевой владелец** | Пользователь с доступом к **нескольким** `clinic_id` под одной `Organization` | Отдельный dependency, проверка `accessible_clinic_ids`, явный `clinic_id` в path/query где нужно; RBAC и аудит |

## Правило до решения

- **Запрет:** новые эндпоинты под `/owner/*` без записи в этом файле (раздел «Принято») и без согласования ARCH.
- **Допустимо:** исправления багов и тесты **без** расширения контракта.
