# Технологический стек

Стек ориентирован на многопользовательскую клиническую платформу: асинхронный backend, реляционное хранилище, очереди, SPA и наблюдаемость в продакшене.

## Backend

- **Python** 3.11.
- **FastAPI** / **Starlette** / **Uvicorn** — REST и ASGI.
- **SQLAlchemy 2** и **asyncpg** — асинхронный доступ к PostgreSQL.
- **Alembic** — версионируемая схема БД.
- **Pydantic v2** и **pydantic-settings** — контракты API и типизированная конфигурация.
- **Celery** с **Redis** как брокером и backend результатов — отложенная обработка, расписание, outbox-доставка.
- **Redis** — также кэш отчётных представлений, rate limiting, коды авторизации и прочие короткоживущие данные.
- **HTTP-клиенты** для исходящих интеграций.
- **Криптография и аутентификация** — современные хэши паролей, JWT, TOTP для чувствительных ролей.
- **Объектное хранилище** по протоколу S3 — медиа и файлы.
- **Метрики Prometheus** — стандартный эндпоинт для скрейпинга.

## Данные и очереди

- **PostgreSQL 16** — основной источник истины; конфигурация допускает повышенный лимит одновременных соединений под нагрузку от API, воркеров и регрессионных прогонов.
- **Redis** — логическое разделение индексов БД под приложение, брокер и результаты задач.

## Frontend

- **React 18**, **TypeScript**, **Vite**.
- **Mantine** — дизайн-система и компоненты.
- **TanStack Query** — кэш и синхронизация с сервером.
- **React Router** — единое SPA с зонами для публичного сайта, пациента, администратора клиники и платформы.
- **PWA** — офлайн-оболочка и кэш статики через Workbox.
- **Vitest** и **Playwright** на стороне фронта; браузерные сценарии дополнительно входят в общий контур Python-тестов.

## Внешние контуры

Интеграции включаются конфигурацией: без ключей и endpoint соответствующий модуль остаётся неактивным или деградирует в безопасный режим.

- **Приём платежей** — провайдер с вебхуками; разделение секретов и лимитов для пациентского контура и контура подписки платформы.
- **Платёжные шлюзы на уровне клиники** — несколько провайдеров, учётные данные в защищённом хранилище, маршрутизация в доменной логике.
- **Уведомления** — электронная почта, SMS, мессенджеры.
- **OAuth** для пациента — крупные провайдеры идентичности по региональным требованиям.
- **Captcha** — защита публичных форм.
- **AI** — вызовы к OpenAI-совместимому API; при отсутствии конфигурации допускаются безопасные заглушки для разработки и тестов.

## Качество и поставка

- **Poetry** для Python, **npm** для фронта.
- **GitHub Actions** — автоматизированные проверки: тесты, сканирование уязвимостей зависимостей, утечек секретов, ссылок в документации, сборка контейнеров, опциональная публикация в публичный registry.
- **Jenkins** — альтернативный корпоративный pipeline с публикацией в приватный registry и выкладкой по политике заказчика.
- **Docker** — отдельные образы backend и статического frontend.
- **Ruff**, **Black**, **mypy** — стиль, формат и статическая типизация backend.

Актуальные версии пакетов задаются lock-файлами Python и npm в репозитории поставки.
